单文件绿色版，放到任何位置即可运行，不写入安装信息。 安装到本机（需管理员权限），自带开始菜单 / 桌面快捷方式、PATH 选项与卸载程序；安装时可自定义目录，也可只装图形界面、只装命令行或两者都装。

本应用可能不兼容你的操作系统：它需要 Windows 8 / 8.1 / 10 / 11（x64）。

基于 AES-256-GCM 认证加密与 PBKDF2-HMAC-SHA256 密钥派生，流式处理大文件。
加密强度、输出位置、删除策略与错误密码次数限制均可配置；简洁、安全、高效，专为 Windows 打造。

极简命令行文件加密工具：加密与解密按文件后缀自动判断（.enc 走解密）。
常用参数：-p 密码、-s 强度（fast / standard / secure / extreme）、-o 输出目录、-k 保留源文件、-w 覆写次数、--delete 安全删除。
Windows x64 单文件无外部依赖，与图形界面版本格式互通，适合脚本与批量处理。

安全提示

认证加密：密文自带认证标签，任何篡改都会被检出。加密后可按设置覆写删除源文件；生成的 .enc 只含密文、不含明文，解密后可直接删除或保留。

关于错误密码次数限制：该机制把剩余次数写在加密文件头中，因此尝试前复制一份文件、失败后还原副本即可绕过，也可以用十六进制编辑器重置计数。它是有效的威慑与减速带，但不能对抗有意为之的攻击者，请勿当作可靠的保密手段。文件头中的保护策略本身已纳入认证，无法通过篡改来关闭保护。

「永久删除文件」不可逆：若自己忘记密码并连续输错达到上限，文件将被真的删除，无法恢复。

核心特性

强加密算法

认证加密：密码错误或密文被篡改都能可靠检出，认证标签随密文一起校验。

大文件支持

流式分块加解密，内存占用恒定，大文件也能流畅处理。

设置面板

语言、主题、输出位置、覆写次数（1/2/3 次）、四档强度（150k / 300k / 450k / 600k 次 PBKDF2 迭代，默认 300k）、保留源文件、诱饵文件、右键菜单开关与随机密码规则（4–128 位）。

现代 UI

WinUI 3 风格自绘界面，圆角控件、悬停与进度动画，支持浅色 / 深色 / 跟随系统主题。

安全删除

与加密/解密并列的独立功能：GUI 覆写 1–3 次，CLI 可用 -w 指定 0–10 次（0 = 不覆写直接删除）；按钮、拖放、右键菜单与命令行四种入口，批量删除带进度条，删除前二次确认。

右键菜单

资源管理器右键即可「用FileEncryptor加密」或「用FileEncryptor安全删除」，多选按批处理；注册在当前用户下，无需管理员权限。

防护机制

源文件可覆写删除防止恢复；可限制错误密码次数，用尽后永久删除或限时锁定解密；支持诱饵文件（可否认加密），被胁迫时可交出假密码。

完全便携

单 EXE 约 700 KB，无需额外 DLL 或运行库——密码学全部使用 Windows 自带的 CNG。
