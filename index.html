FileEncryptor

基于 AES-256-CBC 与 PBKDF2 的流式文件加密工具。
为 Windows 提供简洁、高效的文件加解密体验。

单文件 · 无需安装 · 支持 Windows 10/11

安全提示

加密/解密完成后，程序会对原始文件进行随机数据覆盖并删除，尽力减少残留。建议在本地、非同步目录中使用。

核心特性

强加密算法

AES-256-CBC 结合 PBKDF2-HMAC-SHA256 密钥派生，安全可靠。

大文件支持

流式分块加/解密，内存占用低，轻松处理大文件。

双语界面

加密/解密对话框支持中文与英文切换，方便不同用户。

现代 UI

基于 Direct2D 绘制，圆角输入框与按钮，体验流畅。

安全删除

加密/解密后对原始文件进行一次随机覆盖并删除。

完全便携

单 EXE 文件，无需额外 DLL，开箱即用。
